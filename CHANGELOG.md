## #1 — Generische Vorlage veröffentlicht

- Script zum OAuth-Login mehrerer Codex-Accounts als allgemeine Vorlage
- Alle Konfiguration via Umgebungsvariablen (kein Infisical, kein Anbieter-Lock-in)
- OTP-Abruf über Standard-IMAP (kompatibel mit Gmail, Outlook, IONOS und anderen)
- Kein IMAP konfiguriert? Script fragt OTP manuell ab
- README mit Env-Var-Tabelle und Beispielen für verschiedene Mailserver
